## 先把"兼容 S3"这件事说清楚

S3 是 Amazon Simple Storage Service 的简称，但它早就不只是亚马逊自己的产品了。它更像一套事实标准：一套关于怎么上传、下载、列桶、签名的 API 约定。市面上但凡标榜"S3 兼容"的对象存储，意思就是——你原来写给 AWS S3 的代码、你装的那个 rclone、你用的 PicGo 图床插件，换个 endpoint、换对密钥，就能直接跑。

这点对个人开发者和中小团队特别重要。这意味着你不用为了一个新存储服务商去重写业务代码，也不用在每个工具里重新学一遍配置。迁移的成本，几乎只剩下"把数据 rclone sync 过去"那一步。

## 按量付费到底怎么个"按量"法

很多人对"按量付费"有个误解，以为像水电表那样纯走字计费。实际上国内主流的兼容 S3 对象存储，大多数采用的是**"套餐包 + 超出按量"**的混合模式：你先买一个固定配额的套餐（包含一定存储空间和流量），用超了再按 GB 计费。这样做的好处是日常开销可控，临时爆量也不会被一刀切停服。

雨云的 ROS（RainYun Object Storage）就是这么做的。它把计费拆成两个维度：**存储空间**和**上行流量**。注意一个细节——它**只算上行流量，不算下行流量**。也就是说，你往桶里传文件是不扣流量的，只有从对象存储往外发文件时才扣。如果你还顺手买一台同区域的雨云云服务器，用内网地址互访，连上行流量都免了，等于内网传输零成本。

超出套餐后怎么办？默认是直接停访问（数据还在，能继续上传），但你可以去控制台开**弹性计费**开关，开了之后超出部分就按标准价走，而不是停服。对临时要扛一波流量高峰的项目来说，这个开关比"临时升级套餐"省心多了。

## 几个容易踩的坑

说几个官方文档里写了、但大家经常忽略的点：

第一，**存储桶默认是私有的**。你想让外网通过直链访问图片（比如做图床），得手动去管理面板开"公共访问"。不开的话，所有请求都要带 Access Key 签名，前端直接引用链接是 403。

第二，**删桶之前必须清空**。桶里有文件是删不掉的，先清文件再删桶，否则按钮点了也没反应。

第三，**弹性计费默认是关的**。如果你跑的是面向公众的服务，建议提前开，不然套餐用完那一刻访问直接断，体验很割裂。开了之后哪怕超出也只是按 0.1~0.2 元/GB 走，比"服务中断"划算。

第四，**同区域走内网免流量**。如果你同时买了雨云的云服务器和对象存储，且在同一个区域，用内网 endpoint 访问，上下行流量都不计费。这点对成本敏感的项目一定要利用上。
